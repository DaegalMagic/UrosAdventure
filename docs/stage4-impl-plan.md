# 스테이지4 구현 계획 (림/셰이디)

> 단일 진실원본(SSOT): 메모리 `stage4-rim-shady-spec.md`. 각 단계는 그 스펙을 읽고 따른다.
> 교전 형태 = **림 + 셰이디 2인 동시전**(사료스탕스식). 클리어 조건 = **두 보스 HP 0**.

## 구현 순서 (의존 관계 기반)

```
0. 맵 + 2인 스폰 뼈대  →  1. 림  →  2. 셰이디  →  3. 아공간 2인 연동
   (기반)                  (추격/강타)  (도주/순간이동)  (5%→아공간→30%, 복귀)
```

**근거**: 아공간 연동(HP 임계·복귀·첫처치 봉인)은 **두 보스가 모두 살아있는 상태**를 전제 →
둘이 다 있어야 하므로 마지막. 림은 기존 코드(티그 추격·windup 평타·다야 telegraph·이프리트
변신/플레이어 경직) 재활용이 많아 동시전 골격 검증용으로 먼저. 셰이디는 도주 AI·등 뒤
순간이동·차원문 시퀀서·별도 패링 카운터·낙하 무기 등 신규 시스템이 많아 그다음.

각 단계 끝에 커밋한다(메모리 규칙: 주요 작업 완료 시 묻지 말고 커밋, push는 명시 시).

   회피용 원웨이 발판(=)을 드문드문 배치한다(2~3개 층, 사료스탕스 makeDayaStage 배치

완료 기준: 스테이지4 진입 시 아레나가 그려지고 림/셰이디 더미 둘이 서 있으며, 기존

## 프롬프트 1 — 림 (추격/강타형)

```
메모리 stage4-rim-shady-spec.md의 "림" 섹션을 읽고 구현한다.

- 이동/추격: 플레이어 0.8배(160px/s), 티그식 같은 층 추격(ENEMY_AI.tig, floorPref 0 참조).
- 평타: 0.5초 시전(windup) 후 타격. 범위 세로=캐릭터 동일, 가로=3배. dmg 1.
  (사료스탕스 enemySwing windup 구조 참조.)
- 패턴(쿨 7초, 둘 중 랜덤):
  ① 내려찍기: 1.2초 기 모으기(telegraph) → 바닥 강타. 강타 순간 점프하지 않고 지면에
     있는 플레이어는 2초 행동불가(player stun — 가비아 무적 때림 시 "플레이어 경직"
     로직 재활용). dmg 1. 패링 불가(가정).
  ② 광역 강타: 1.2초 기 모으기 → 평타 범위의 가로 5배·세로 5배. 림과 겹쳐도 피격되되
     림 뒤쪽은 비피격(범위를 림 전방으로 치우치게 조절). dmg 2. 패링 가능하지만 패링
     시 "플레이어"가 0.3초간 행동불가(패링에 리스크).
- ENEMY_AI에 rim role 추가. 셰이디 없이 림 단독으로 동작 검증 가능해야 한다.

완료 기준: 림이 160px/s로 같은 층 추격하며 0.5초 평타, 7초마다 ①/②가 랜덤으로 나오고,
①은 점프로 회피 가능(안 하면 2초 스턴), ②는 뒤로 돌면 안 맞고 패링하면 플레이어 0.3초
행동불가. 커밋한다.
```

## 프롬프트 2 — 셰이디 (도주/순간이동형)

```
메모리 stage4-rim-shady-spec.md의 "셰이디" 섹션을 읽고 구현한다.

- 평소 이동: 플레이어 반대 x방향으로 300px/s(플레이어×1.5) 도주.
- 점프: 0.373초마다 판정, 10% 확률로 최대 점프(JUMP_SPEED, ≈150px).
- 접근 평타: 좌우 맵 끝 도달 또는 플레이어와 ≥500px → 차원문 열고 플레이어가 보는 방향
  뒤(등 뒤)로 순간이동해 평타. dmg 1, 일반 패링 가능.
- 차원문 난사(쿨 13초):
  · 차원문 위치 = 플레이어 정면 0° 기준 전방 ±70°/후방 ±70°, 60px 거리에서 랜덤
    (상·하 각 40° 쐐기 제외).
  · 시퀀스: 열림 → 0.3초 후 공격 → 즉시 숨김 → 0.2초 후 다음 차원문, 6회 반복.
  · 누적 3회 패링 → 패턴 즉시 취소 + 3초 그로기. 단 이 패턴의 패링·그로기는 전역 그로기
    게이지(GROGGY_GAUGE_MAX)와 무관한 별도 카운터(키디언 sealParries 구조 참조).
  · 6회 완주 시: 맵 최상단에서 무기 낙하 — 크기 플레이어 가로 5배·세로 7배, 낙하
    가속도 = GRAVITY, dmg 2, 패링 불가. (3패링 취소 시 낙하 없음.) 낙하 무기는
    hittables/투사체 구조 참조해 떨군 오브젝트로 처리.
- ENEMY_AI에 shady role 추가. 림과 함께 2인 동시전으로 둘 다 각자 패턴이 나와야 한다.

완료 기준: 셰이디가 도주·랜덤 점프하다 맵 끝/500px에서 등 뒤 평타, 13초마다 차원문
6연타가 각도/타이밍대로 나오고, 3패링 시 취소+3초 그로기(게이지 무관), 6회 완주 시
거대 무기가 중력 낙하(패링불가 dmg2). 커밋한다.
```

## 프롬프트 3 — 아공간 2인 연동

```
메모리 stage4-rim-shady-spec.md의 "공통 — 아공간" 섹션을 읽고 구현한다. 림·셰이디가
이미 있어야 한다.

- 한 쪽 HP ≤ 5% → 아공간으로 이동(피격/공격 정지, 화면에서 사라짐) → 일정 후 복귀,
  복귀 시 HP를 30%로 회복.
- 아공간 체류 중 상대가 죽으면 → 이동한 쪽 즉시 복귀 + 체류시간 비례 HP 회복.
- 하나가 처치되면 남은 한 쪽은 더 이상 아공간에 들어가지 않는다(아공간 회피는 둘 다
  생존 중일 때만). → 첫 처치 이후 생존자는 정상 처치 가능.
- 클리어 판정 = 두 보스 HP 0(combat.js의 사망/클리어 처리에 연결).
- group 상호 참조로 상대 생존/사망·아공간 상태를 공유한다(사료스탕스 trio 연동 참조).

완료 기준: 한 보스를 5%까지 깎으면 아공간으로 도망가 30%로 복귀하고, 둘 다 살아있는
동안엔 즉사가 불가하며, 한쪽을 먼저 처치하면 남은 보스는 아공간 없이 마무리되어 두
보스 HP 0으로 스테이지 클리어가 성립한다. 커밋한다.
```
