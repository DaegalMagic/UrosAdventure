# 스테이지3 구현 계획 (실라/나이아/이프리트/가비아)

> 단일 진실원본(SSOT): 메모리 `stage3-ifrit-spec.md`. 각 단계는 그 스펙을 읽고 따른다.
> 클리어 조건 = **이프리트 + 가비아 HP 0** (실라·나이아는 봉인만, 죽지 않음).

## 구현 순서 (의존 관계 기반)

```
0. 맵 + 뼈대  →  1. 이프리트  →  2. 가비아  →  3. 나이아  →  4. 실라
   (기반)        (근접 핵심)      (방어막 연동)   (레이저/파도)   (반사·나이아 의존)
```

**근거**: 실라 반사방향은 나이아 생존 여부에 의존 → 나이아가 먼저. 나이아 레이저는
이프리트/가비아에 작용(피해/회복) → 둘이 먼저. 모든 동작이 4층 맵을 전제 → 맵이 0번.

각 단계 끝에 커밋한다(메모리 규칙: 주요 작업 완료 시 묻지 말고 커밋, push는 명시 시).

## 프롬프트 0 — 스테이지3 맵 + 스폰 뼈대

```
스테이지3(실라/나이아/이프리트/가비아) 구현을 시작한다. 먼저 메모리
stage3-ifrit-spec.md를 읽고 "맵 구조"·"전용 층 표면 y" 섹션을 따른다.

작업:
1) map.js에 makeStage3() 추가 — 4층, 각 층이 맵 가로 전체를 꽉 채움(좌우 공백
   없음). 층 표면 y = 500/360/220/80 (= row 25/18/11/4, 간격 140px=7타일).
   1층은 #(바닥), 2~4층은 원웨이 발판(=)으로 가로 전체. 플레이어 스폰 P는 1층
   왼쪽. STAGES["스테이지 3"]를 이 맵으로 교체(현재 makeFlatStage 더미 제거).
2) 스테이지별 층 좌표 분리: 전역 FLOOR_SURFACES_Y에 의존하던 부분을 stage
   객체의 floorSurfaces로 옮긴다. parseStage가 stage.floorSurfaces를 갖도록 하고
   (스테이지3=[80,220,360,500], 그 외=기존 [260,340,420,500]), floorOf/
   floorSurfaceY와 enemy.js의 세로추격 AI(enemy.js:62 부근)가 stage.floorSurfaces를
   쓰게 한다. 기존 스테이지 동작은 불변이어야 한다(회귀 금지).
3) main.js startStage()에 "스테이지 3" 분기 추가 — 4보스를 makeEnemy로 배치하되
   지금은 AI 없이 가만히 서 있는 더미(이프리트/가비아는 HP 80, 실라/나이아는
   화면 밖 모서리 위치만). enemies group 연결.

완료 기준: 스테이지3 진입 시 4층 맵이 그려지고, 플레이어가 2단점프로 2층까지
올라가지며(여유 약 32px), 기존 스테이지1/2는 그대로 동작. 커밋한다.
```

## 프롬프트 1 — 이프리트

```
메모리 stage3-ifrit-spec.md의 "이프리트" 섹션을 읽고 구현한다.

- 이동/추격: 티그와 동일(ENEMY_AI.tig 참조, floorPref 0).
- 거리 분기: 플레이어와 직선거리 ≥200px → 패턴 A/B 랜덤(쿨 5초), <200px → 평타.
- 패턴 A 점프슬램: 포물선 점프. 공중 내내 패링 윈도. 패링 성공 → 뒤로 20px를
  0.1초간 밀림(경직·변신 없음). 실패(착지) → 거대 불꽃변신(가로·세로 3배, 3초
  무적, 겹치면 0.1초당 0.1 dmg), 변신 해제 직후부터 5초 쿨.
- 패턴 B 불기둥: 발밑 telegraph 1.5초 후 즉발(다야 가시 telegraph 재활용,
  projectiles.js 참조). 폭=캐릭터폭, 높이=캐릭터2배, 패링불가, dmg 1.
- HP 80. ENEMY_AI에 ifrit role 추가.

완료 기준: 이프리트 단독으로 세 행동이 거리/쿨대로 나오고 패링 분기가 맞게
동작. 커밋한다.
```

## 프롬프트 2 — 가비아 (+ 동적 붕괴)

```
메모리 stage3-ifrit-spec.md의 "가비아"·"가비아 HP 연동 맵 붕괴" 섹션을 읽고
구현한다.

- 카이팅 이동: 플레이어 250px 안 → 물러남, 400px 밖 → 안 나감. 속도 ~90.
- 돌 던지기: 쿨 2~4초, dmg 1, 속도 300, 패링 시 반사각 반사(다야 P1 반사
  projectiles.js:384~ 재활용).
- 공유 방어막(이프리트+가비아, 10초 주기, 지속 2초, 방어력 +0.8, HP없는 시간제;
  비비 shield 구조 combat.js 참조). 방어막 중 피격된 쪽은 해제 0.5초 후 자기중심
  폭발(가로·세로 1.4배, dmg 1, 패링불가). 매 3번째 시전은 방어막 대신 무적(HP
  적은 쪽 하나, 1.5초; 때리면 플레이어 0.5초 경직 + 무적 즉시 해제).
- HP 80. ENEMY_AI에 gabia role 추가.
- 동적 붕괴: 가비아 HP가 64/48/32/16에 도달할 때마다 각 층을 랜덤 20%씩 무너뜨림
  (stage.tiles[r][c]=TILES["."]로 칸 제거, 누적). 단 불변 보장 우선 — ① 바닥→
  최상층 경로 존재 ② 최상층 발판 좌우 이동 가능. 이 둘을 깨는 칸은 무너뜨리지 않음.

완료 기준: 카이팅·돌반사·방어막/폭발/무적이 스펙대로 동작하고, 가비아 HP를
깎으면 맵이 단계적으로 무너지되 항상 최상층 도달·이동이 가능. 커밋한다.
```

## 프롬프트 3 — 나이아

```
메모리 stage3-ifrit-spec.md의 "나이아" 섹션을 읽고 구현한다. 이프리트·가비아가
이미 있어야 한다.

- 위치: 오른쪽 위 모서리(화면 밖). 물줄기 레이저: 각도 랜덤, 전조 1.2초 → 발사,
  지속 1.2초, 쿨 12초, 패링불가, dmg 2, 두께 40px.
- 레이저 명중 연동: 이프리트에 닿으면 이프리트 피해 / 가비아에 닿으면 가비아
  회복, 수치는 플레이어 피해와 동일(=2).
- 3번째 공격마다 다음 공격은 파도: 카메라 왼쪽에 주의표시 2초 → 왼→오 진행,
  속도=플레이어 이동속도×1.2, 가로=맵 가로×3, 1초당 1 다단히트. 최상층(y=80)
  발판 위에 있어야만 회피. 파도가 맵에서 완전히 사라진 뒤에야 쿨 시작(주의표시~
  파도 존재 동안 쿨 정지).
- 봉인되면 발사 중지(봉인 카운터는 실라 단계에서 연결).
- ENEMY_AI에 naia role 추가(stationary, 화면 밖).

완료 기준: 레이저가 전조→발사로 나가고 이프리트/가비아에 피해·회복을 주며,
3번째에 파도가 나와 최상층에서만 회피 가능. 커밋한다.
```

## 프롬프트 4 — 실라

```
메모리 stage3-ifrit-spec.md의 "실라" 섹션을 읽고 구현한다. 나이아가 이미 있어야
한다.

- 위치: 왼쪽 위 모서리(화면 밖). 포물선 화살: 시작점 랜덤, 발사각 아래 0°±65°,
  쿨 5~8초, dmg 1, 패링 가능.
- 패링 반사(속도 2배): 반사 방향 = 살아있는 저격수 모서리 — 나이아 생존 시
  오른쪽 위(나이아), 나이아 무력화 후 왼쪽 위(실라).
- 봉인 카운터: 반사 화살이 모서리 보스 명중 누적 4회 → 나이아 무력화(발사 중지),
  추가 4회(누적 8) → 실라 무력화. 키디언 sealParries 구조 참조.
- 화살 바닥 착탄: 패링 안 한 화살이 층 표면에 닿으면 층별 25% 확률로 화살 소멸 +
  잡몹 생성. 잡몹 HP 0.5, 플레이어와 가로 20px 내 근접 시 100×100 폭발, 폭발
  전에 맞으면 그냥 소멸.
- ENEMY_AI에 sila role 추가(stationary, 화면 밖).

완료 기준: 화살 패링→반사 방향이 나이아 생존에 따라 바뀌고 4/8회 봉인이
동작하며, 미패링 화살이 잡몹을 만들고 잡몹이 근접 폭발/피격 소멸한다.
이프리트+가비아 HP 0으로 스테이지 클리어가 성립하는지 확인. 커밋한다.
```
