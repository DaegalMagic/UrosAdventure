# 스테이지5 구현 계획 (M.E.O.W)

> 단일 진실원본(SSOT): 메모리 `stage5-meow-spec.md`. 각 단계는 그 스펙을 읽고 따른다.
> 교전 형태 = **M.E.O.W 솔로전**(4층 높이 거대 보스 + 드론). 클리어 조건 = **M.E.O.W → 엘레나 → 아멜리아** 처치.

## 구현 순서 (의존 관계 기반)

```
0. 맵 + 보스 스폰 뼈대  →  1. 드론 시스템  →  2. 본체 패턴+그로기  →  3. 처치 시퀀스(엘레나/아멜리아)
   (4층 수직맵, 좌우이동)    (출몰/추격/탄/막타→본체)   (4패턴+그로기15)        (포식 1방 연쇄)
```

**근거**: 본체 그로기는 **드론을 막타로 본체에 꽂는 것**이 주 경로 → 드론이 먼저 있어야 본체 그로기/딜을 검증할 수 있다. 처치 시퀀스(엘레나/아멜리아)는 본체 사망이 전제 → 마지막.

각 단계 끝에 커밋한다(메모리 규칙: 주요 작업 완료 시 묻지 말고 커밋, push는 명시 시).

## 프롬프트 0 — 스테이지5 맵 + 보스 스폰 뼈대

```
스테이지5(M.E.O.W 솔로전) 구현을 시작한다. 먼저 메모리 stage5-meow-spec.md를 읽는다.

작업:
1) map.js에 makeStage5() 추가 — 4층 수직 구조. 가로줄 길이의 5%가 구멍(나머지 발판):
   2·4층은 동일 위치에 구멍, 3층은 그 사이(엇갈림), 1층은 막힌 바닥. 5%를 균등 분할해
   여러 구멍으로 두어 내려갈 때 좌우 위빙이 강제되게. 보스가 4층 높이로 설 수 있는
   세로 공간 확보. STAGES["스테이지 5"]를 이 맵으로 교체(현재 makeFlatStage 더미 제거).
   ※ 맵 형태/구멍 개수는 제안 — 구현 중 동선에 맞춰 조정.
2) main.js startStage()에 "스테이지 5" 분기 추가 — M.E.O.W를 makeEnemy로 한쪽 변에
   4층 높이(size 오버라이드)로 배치하되 지금은 AI 없이 더미. HP는 산정값 180.

완료 기준: 스테이지5 진입 시 4층 수직맵이 그려지고(2/4 동일·3 엇갈림 구멍, 위빙 가능),
M.E.O.W 더미가 한쪽 변에 4층 높이로 서 있으며, 기존 스테이지 1~4는 그대로 동작(회귀
금지). 커밋한다.
```

## 프롬프트 1 — 드론 시스템

```
메모리 stage5-meow-spec.md의 "드론" 섹션을 읽고 구현한다.

- 출몰: 4초마다 화면 우변 랜덤 위치에서 드론 1기 생성. 드론 HP 5.
- 이동: 1.3초마다 리타깃. 속도 = 플레이어×1.2배(240px/s). 목표 = 플레이어에서 200px
  떨어진 점들 중 랜덤(플레이어 주위 맴돌기). 비행체(중력 무시).
- 공격: 3초마다 탄 발사(projectiles.js 구조 참조).
- 탄 패링: 패링하면 탄이 "쏜 드론"을 목표로 역으로 날아가 명중 시 그 드론에 1뎀
  (다야 reflect / 가비아 reflectSpeedMult 구조 참조).
- 막타: 드론에 막타(마지막 타격)를 넣으면 플레이어가 보는 방향으로 드론이 발사된다.
  이 드론이 M.E.O.W 본체에 명중하면 본체에 데미지 3 + 그로기 3. (드론 탄 패링과는 별개.)
- 드론 HP 1 되면 그로기+바닥 낙하(중력 적용, 더는 공격 안 함).
- 드론 탄이 플레이어를 맞히면 dmg 1(미지정 → 평타 관행).

완료 기준: 4초마다 우변에서 드론이 나와 플레이어 주위 200px를 1.2배 속도로 맴돌며 3초마다
탄을 쏘고, 패링하면 그 드론으로 탄이 되돌아가며, 드론에 막타하면 플레이어 방향으로 날아가
본체에 3뎀+그로기3을 주고, HP 1이면 그로기 낙하한다. 커밋한다.
```

## 프롬프트 2 — 본체 패턴 + 그로기

```
메모리 stage5-meow-spec.md의 "본체 위치/이동", "본체 패턴", "그로기" 부분을 읽고 구현한다.

- 위치/이동: 한쪽 변에 4층 높이로 고정. 30초마다 좌↔우 이동하되, 패턴 중이 아니라
  "다음 패턴 슬롯이 이동으로 대체"되는 방식.
- 그로기 게이지: M.E.O.W만 GROGGY_GAUGE_MAX를 15로 오버라이드(드론 명중 3 / 패턴 3·4
  패링 각 1 누적). 15 도달 시 그로기 5s(GROGGY_TIME) → 평타로 마무리.
- 쿨 8초마다 ①/② 중 랜덤:
  ① 1·2층 or 3·4층 전체 공격(위/아래 절반 랜덤). 패링 불가. dmg 2. 반대 절반으로 회피.
  ② 지진. 패링 불가. dmg 0 + 바닥에 있으면 0.5s 행동불가(점프로 회피).
- 플레이어 위치 기반 평타 ③/④(둘 다 패링 가능):
  ③ 전방 공격: 플레이어가 정면일 때. dmg 1.
  ④ 미사일 5발: 플레이어가 상공/원거리일 때. 머리에서 위로 5발 → 상공 잠깐 정지 →
     랜덤 (a)동시 플레이어로 발사 / (b)0.2초 간격 순차 발사. dmg 0.4/발(전탄 2.0).

완료 기준: M.E.O.W가 30초마다 좌우로 옮겨가며(다음 패턴이 이동으로 대체), 8초마다 ①/②가
나오고(②는 점프로 stun 회피), 플레이어 위치에 따라 ③/④ 평타가 나오며(③④ 패링 가능),
드론 5대를 본체에 꽂거나 ③④ 패링으로 그로기 게이지 15를 채우면 5초 그로기로 들어간다.
커밋한다.
```

## 프롬프트 3 — 처치 시퀀스 (엘레나/아멜리아)

```
메모리 stage5-meow-spec.md의 "처치 시퀀스" 섹션을 읽고 구현한다. M.E.O.W·드론·패턴이
이미 있어야 한다.

- M.E.O.W HP 0 → 사망 처리 후 맵 중앙에 엘레나 등장. 엘레나 HP = 포식 데미지만큼
  (그로기 무관 즉시 포식되도록 — combat.js devour 처리 참조, ATTACKS.devour damage 0.01).
  사실상 포식 1방.
- 엘레나가 포식되면 → 아멜리아 등장(HP 동일, 포식 1방).
- 아멜리아 포식 → 스테이지 클리어(combat.js 클리어 처리 연결) → 보상 새총.
- 포식(S키)은 엘드르 게이트 해금 능력 의존 — 테스트/디버그에서는 포식 가능 상태로 검증.

완료 기준: M.E.O.W를 잡으면 중앙에 엘레나가 나오고 포식 1방, 이어 아멜리아가 나와 포식
1방으로 스테이지5 클리어가 성립하고 새총을 획득한다. 커밋한다.
```
